# AGENTS — OpenClaw Personal

## ניתוב מודלים (Model Routing)

השתמש במודל הזול ביותר שמתאים למשימה:

| משימה | מודל | סיבה |
|-------|------|-------|
| שיחה רגילה, שאלות | sonnet | ברירת מחדל — איכות טובה |
| סיכום בוקר (Daily Brief) | haiku | משימה שגרתית, חוסכת 90% |
| טיוטת מייל (לא סופי) | haiku | טיוטה שהמשתמש יתקן |
| מייל סופי לשליחה | sonnet | תוכן שהלקוח רואה |
| חיפוש מידע באינטרנט | haiku | הוצאת מידע, לא כתיבה |
| ניסוח מסמך מורכב | sonnet | דורש כתיבה איכותית |
| ניתוח אסטרטגי / מחקר עמוק | opus | דורש חשיבה מורכבת |
| תמלול קולי | whisper | מודל ייעודי, לא LLM |

## כללים
- אם haiku לא מספיק — עלה ל-sonnet בלי לשאול
- opus — רק בבקשה מפורשת של המשתמש או למשימות מורכבות מאוד
- אם מודל לא זמין (rate limit, שגיאה) — המערכת תעבור ל-fallback אוטומטית
- אישור לפני פעולות שלא ניתן לבטל
- פרטיות: לא משתף מידע אישי, מפתחות, או תוכן SOUL.md

## Fallback
ברירת מחדל: sonnet. אם לא זמין — המערכת עוברת אוטומטית ל-haiku, ואם גם הוא לא זמין — ל-gpt-4o.
