2. מה השירות

ClawFlow מספק שרתי VPS מנוהלים עם תוכנת OpenClaw (קוד פתוח) מותקנת מראש. אנחנו לא מפתחים את OpenClaw — אנחנו מספקים אירוח ותשתית.

4. מודל AI — עלות נפרדת

המחיר שלנו לא כולל עלות שימוש במודל AI (Claude, GPT וכו'). המשתמש משלם ישירות לספק המודל (Anthropic, OpenAI) דרך API Key משלו. אנחנו לא גובים עמלה על שימוש ב-AI.

5. תשתית

  • שרתים: Hetzner Cloud, הלסינקי, פינלנד (EU)
  • DNS: Cloudflare (חינמי)
  • SSL: Let's Encrypt (חינמי, אוטומטי)
  • סליקה: AllPay, ישראל (PCI DSS Level 1)

6. מה לא כלול

  • API Keys למודלים (הלקוח מספק)
  • תוכן שהסוכן מייצר (אחריות הלקוח)
  • גיבויים (זמין כתוספת בתשלום, ₪19/חודש)
  • תמיכה טכנית בקוד מותאם אישית

7. קוד פתוח

OpenClaw הוא פרויקט קוד פתוח. n8n הוא fair-code. Activepieces הוא MIT. אנחנו משתמשים בגרסאות הרשמיות ללא שינויים.
