המודל — אתם משלמים רק על אירוח

ClawFlow עובד על מודל פשוט: אתם משלמים רק על שירותי אירוח. שרת VPS ייעודי שלכם בענן Hetzner באירופה. זה מה שעולה כסף — כי שרת עולה כסף.

כל השאר — בלי מרווח מצדנו:

  • סוכני AI — OpenClaw (קוד פתוח), מותקנים על השרת שלכם
  • אינטגרציות — Google, Microsoft, Meta, Telegram, WordPress — חיבור דרך ה-OAuth שלכם
  • מודלים — אתם משלמים ישירות לספק (Anthropic, OpenAI). אנחנו לא מתווכים
  • כלי אוטומציה — Activepieces (MIT, קוד פתוח)
  • זיכרון — Mem0 + Qdrant, רצים על השרת שלכם
  • אבטחה, SSL, DNS, עדכונים, גיבויים — כלול בלי תוספת
למה? כי אנחנו מאמינים שההוצאה על AI צריכה ללכת ישירות לספקי המודלים — לא לעוד שכבת תיווך. ככה אתם משלמים פחות, ואנחנו מרוויחים מהאירוח עצמו.

שלב 3 — הקמה אוטומטית (3 דקות)

המערכת מקימה שרת VPS חדש, מתקינה OpenClaw, מגדירה DNS + SSL, מתקינה כלי אוטומציה, מגדירה אבטחה, ומפעילה הכל. אתם רואים את זה בזמן אמת — 4 שלבים עם ✓.

שלב 4 — הגדרה

שלב 5 — עובד

הסוכן מחובר לטלגרם, ליומן, למייל. שולח סיכום בוקר. עונה על שאלות. מנסח מיילים. מחפש מידע. הכל דרך Approval Queue — אתם מאשרים לפני כל פעולה.

  • שמירה אוטומטית — כשהסוכן מגלה עובדה חשובה, הוא שומר אותה
  • שליפה אוטומטית — לפני כל תגובה, הסוכן בודק אם יש זיכרונות רלוונטיים

אבטחה — הגישה שלנו

אבטחה היא לא פיצ'ר — היא שכבה שעוברת בכל דבר. הנה מה שעשינו:

בידוד מלא

כל לקוח מקבל שרת VPS ייעודי ומבודד לחלוטין. אין שיתוף משאבים בין לקוחות. מה שרץ אצלכם — רץ רק אצלכם.

הרשאות מוגבלות

  • Gmail — קריאה + שליחה בלבד. הסוכן לא יכול למחוק מיילים
  • Microsoft — קריאה + שליחה בלבד. אותו דבר
  • Drive — קריאה בלבד. לא יכול לערוך, למחוק, ליצור
  • Calendar — גישה מלאה (נדרש ליצירת אירועים). אישור לפני מחיקה

Approval Queue

כל פעולה שהסוכן מבצע — שליחת מייל, פרסום פוסט, תגובה לביקורת — עוברת דרך תור אישור. אתם רואים, מאשרים, מתקנים או דוחים. עם קיצורי מקלדת: א=אשרו, ת=תקנו, פ=פרסמו, ד=דחו.

כללי סוכן

  • כל תהליך מוגבל ל-10 דקות מקסימום
  • אם משימה נכשלת 3 פעמים — הסוכן עוצר ומדווח
  • הסוכן לא משתף API Keys, סיסמאות, או זיכרונות עם אף אחד

תשתית

  • SSL (HTTPS) אוטומטי — Let's Encrypt עם חידוש אוטומטי
  • חומת אש (UFW) — רק פורטים 22, 80, 443 פתוחים
  • משתמש ייעודי (non-root) — OpenClaw לא רץ כ-root
  • Qdrant (זיכרון) — מאזין רק על localhost, לא חשוף לרשת
  • עדכונים אוטומטיים — כל לילה ב-4:00
  • גיבויים — כל לילה ב-3:00, 7 ימי היסטוריה
  • Self-Healing — 10 בדיקות כל 5 דקות, תיקון אוטומטי

אימות

  • אימות דו-שלבי (2FA) בדשבורד
  • JWT עם HMAC-SHA256
  • OTP בן 6 ספרות באימייל לרישום
  • AllPay webhook — אימות חתימת HMAC

ניטור אבטחה

  • Self-Healing Agent — 10 בדיקות כל 5 דקות + תיקון אוטומטי
  • Rate limiting — הגנה מפני שימוש לרעה
  • התראות Telegram — על כשלים, ניסיונות כניסה חשודים, שימוש חריג
  • גיבוי יומי עם 7 ימי היסטוריה + שחזור בלחיצה

הדשבורד — הכל במקום אחד

  • בית — סטטוס הסוכן, Approval Queue עם קיצורי מקלדת, התראות
  • צ'אט — ממשק צ'אט ישירות בדפדפן, מסונכרן עם Telegram
  • סוכנים — הגדרות, שאלון עסקי, לוח זמנים, סאב-אגנטים, זיכרון
  • אינטגרציות — כל החיבורים. Google, Microsoft, Meta, Telegram, WhatsApp, WordPress, SMTP, חיפוש, תמונות
  • מפתחים — מנהל קבצים, Terminal מלא (SSH), לוגים של כל השירותים, סטטיסטיקות שרת (CPU, RAM, Disk), ניהול גיבויים
  • הגדרות — פרופיל, תוכנית, אבטחה דו-שלבית, ריפוי אוטומטי, קישור הפניית חברים, ביטול

LLM Router — אופטימיזציה אוטומטית

לא כל משימה צריכה את המודל הכי יקר. ClawFlow מנתב כל קריאת AI למודל המתאים ביותר:

  • ניתוח טכני (RSS, HTML, דדופליקציה) → TypeScript בלבד, בלי LLM — $0.00
  • משימות פנימיות (לא נראות ללקוח) → Ollama מקומי (אם מותקן) — $0.00
  • עברית, לא סופי (טיוטות, ניתוח) → Claude Haiku — חסכון 90%
  • תוכן סופי לפרסום → Claude Sonnet — איכות מקסימלית
  • אסטרטגיה ומחקר עמוק → Claude Opus
התוצאה: $3–5 לחודש במקום $18–25 על AI. החיסכון הזה הולך ישירות ללקוח — כי עלות ה-API היא שלכם, לא שלנו.

Self-Healing — השרת מתקן את עצמו

כל 5 דקות, daemon על השרת שלכם מריץ 10 בדיקות:

  • SSL — מתי פג? חידוש אוטומטי אם פחות מ-7 ימים
  • דיסק — מעל 85%? ניקוי אוטומטי (Docker, לוגים)
  • RAM — מעל 90%? ריסטארט Gateway
  • CPU — תקוע מעל 90% ל-10 דקות? ריסטארט
  • Gateway — לא מגיב? ריסטארט אוטומטי
  • Qdrant (זיכרון) — נפל? הרמה מחדש
  • כלי אוטומציה — לא מגיב? הרמה מחדש
  • Cron jobs — 3+ כשלים רצופים? התראה
  • OpenClaw עדכון — גרסה חדשה? התראה
  • API rate limit — נגמרו קרדיטים? התראה

אם רוצים — אפשר לכבות את הריפוי האוטומטי ולקבל רק התראות בטלגרם.

שאלות נפוצות

מה ההבדל בין ClawFlow לבין להתקין OpenClaw לבד?

בהתקנה עצמאית אתם צריכים: לשכור שרת, להתקין Docker, להגדיר OpenClaw, לטפל ב-SSL ו-DNS, להגדיר אבטחה, לבנות חיבורים ל-Google/Microsoft ידנית דרך Cloud Console, ולתחזק הכל בעצמכם. ב-ClawFlow — הכל מוכן תוך 3 דקות עם Dashboard מלא.

מה קורה עם הנתונים שלי אם אני מבטל?

השרת נשמר 7 ימים אחרי ביטול. אפשר להוריד backup בלחיצה מהדשבורד. אחרי 7 ימים — הכל נמחק לצמיתות.

אפשר להעביר את הסוכן לשרת אחר?

כן. OpenClaw הוא קוד פתוח. הנתונים שלכם — שלכם. אפשר להוריד backup ולהעביר לכל שרת אחר.

כמה עולה ה-AI בנפרד?

תלוי בשימוש. LLM Router שלנו מביא את העלות ל-$3–5 לחודש בממוצע. אתם משלמים ישירות ל-Anthropic או OpenAI — אנחנו לא מתווכים ולא מוסיפים מרווח.

הסוכן יכול למחוק מיילים שלי?

לא. ההרשאות מוגבלות ברמת ה-API — קריאה ושליחה בלבד. הסוכן פיזית לא יכול למחוק או לשנות מיילים קיימים.

האם הנתונים שלי מוצפנים?

כן. כל התקשורת דרך HTTPS (SSL). הנתונים על השרת מוגנים בחומת אש. API Keys מאוחסנים בקבצי הגדרה מוצפנים על השרת שלכם — לא אצלנו.

יש תקופת ניסיון?

כן — 14 ימים בחינם, ללא כרטיס אשראי. דרך קישור הפניה מלקוח קיים.
