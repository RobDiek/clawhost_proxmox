  1. Enhanced Conversions for Web — לא מופעל. דרישת חובה ב-2026; משפיע על דיוק Smart Bidding ב-10%-60%. אסור להשיק בלי זה.
  2. Consent Mode v2 — לא מותקן. דרישה רגולטורית באירופה ובישראל. ללא זה Google עלולה לחסום נתוני המרות בלקוחות שלא נתנו הסכמה.

  4. קישור אירוע WhatsApp Click כ-Conversion Action ב-Google Ads. 98% מהמרות היסטוריות הן לחיצות WhatsApp — אם לא נמדדות, Smart Bidding מתאמן על מדגם חסר.

💬 הגדרת WhatsApp Click כ-Primary Conversion

זהו הצעד הקריטי ביותר — בלעדיו כל המתמטיקה של ה-CPA לא תעבוד.

📋 6 צעדים מסודרים:

  1. בדקו ב-GA4 שהאירוע click_on_whatsapp כבר נורה (Reports → Engagement → Events). אם כן — עברו לצעד 2.
  2. ב-GTM (סטוראג'4יו): צרו תג חדש מסוג Google Tag (Tag Configuration → Google Ads Conversion Tracking), שם: awct - whatsapp_click, יורה על Custom Event matching click_on_whatsapp.
  3. ב-Google Ads (אחרי שלב 5): Tools & Settings → Conversions → New Conversion Action → Website → Set up manually:
    • Category: Lead → Submit lead form
    • Name: WhatsApp Click
    • Value: Use the same value for each conversion = ₪750 (avg deal value, אושר על ידי הלקוח)
    • Count: One per click (whatsapp click מצדיק ספירה אחת — לא כל ביקור חוזר באותה הסרטון)
    • Click-through conversion window: 30 days (חוזה אחסון ארוך)
    • Attribution model: Data-driven אם זמין, אחרת Last-click
    • Primary conversion goal — מסומן ✓
  4. קבלו את ה-Conversion ID ו-Conversion Label מ-Google Ads → חזרו ל-GTM → טענו לתג שיצרתם בצעד 2.
  5. Enhanced Conversions: ב-Google Ads תחת אותו Conversion Action → Settings → Enhanced Conversions: ON → Code = Google Tag, ה-form fields (email, phone) יישלחו hashed אוטומטית. חובה לפני השקה.
  6. Consent Mode v2: ב-GTM → Variables → Built-in: הפעילו את כל ה-Consent State variables. הוסיפו תג Consent Initialization — All Pages שמגדיר default consent = denied, ומעדכן ל-granted אחרי שהמשתמש מאשר ב-CMP (אם יש על האתר). אם אין CMP — Google Ads עדיין יעבוד אבל באיכות נתונים נמוכה.
אימות לפני השקה: Tag Assistant Live → לחצו על כפתור WhatsApp באתר → ודאו שמופיע "Conversion Hit Sent" ב-Google Ads תוך 5 שניות, וב-Google Ads → Conversions → סטטוס ה-Action חייב להיות Recording conversions (לא "No recent conversions"). אם הסטטוס אדום — אל תשיקו!
